# 《麦田里的钢铁》—— 机器人详细造型设计

> 版本：V2.0 | 更新日期：2026-05-22 | 基于网络资料+机器人学知识优化
> 用途：AI生成 / 3D建模 / Cosplay / 道具制作

---

## 针对林一鸣角色的机器人项目实践合理性

林一鸣作为一个普通一本院校的自动化专业学生（非985/211），他的机器人制作路径应该符合**学生项目级别的可行性**：

- **本科阶段**：MG996R/MG995舵机（淘宝几十块钱）、Arduino/STM32F103C8T6（Blue Pill，十几块钱）、3D打印PLA（学校实验室或淘宝代打）
- **研一阶段**：LX-16A/LX-224串口舵机（一两百一个，带角度反馈和控制）、自主设计的STM32F4驱动板、PETG/碳纤尼龙（比PLA更结实）
- **研二+阶段**：IronHand赠送的谐波减速器电机模组、激光雷达（YDLIDAR X4/RPLIDAR A1，几百块的无刷版）、Jetson Nano / RK3588（跑视觉/LLM推理）

全剧不能出现超出这个技术层次的设计——**比如EtherCAT总线、力控关节、自研谐波减速器、全同步带传动**等林一鸣个人不可能做到的东西不应出现。以下设计严格遵循这一原则。

## 7 小七 V0.1（研二·原型机）

> 全剧技术合理性：40cm桌面级人形原型机，验证运动控制方案。所有零件通过3D打印+标准件采购实现。

### 尺寸比例

| 部位 | 尺寸 | 说明 |
|------|------|------|
| 总高 | ~40cm | 桌面级，与Spot Micro这种开源项目尺寸接近 |
| 躯干 | 12cm×7cm×6cm（高×宽×深） | 内部放置主控板（STM32F407或类似）和IMU |
| 大腿 | ~12cm | PLS打印的中空管状结构 |
| 小腿 | ~11cm | 同大腿，足端预留传感器安装位 |
| 上臂 | ~7cm | 两段结构，肩关节含一个水平+一个垂直舵机 |
| 下臂 | ~7cm | 末端为两指平行夹具 |
| 足部 | ~6cm×4cm | 扁平结构，底面贴防滑硅胶垫 |

### 动力系统

| 关节组 | 舵机型号 | 数量 | 说明 |
|--------|---------|:----:|------|
| 髋关节 | LX-16A（Metal Gear Serial Servo） | 2（每条腿） | 一个水平旋转（髋关节外摆/内收）、一个垂直（髋关节前屈/后伸） |
| 膝关节 | LX-16A | 1（每条腿） | 单轴前后屈伸 |
| 踝关节 | SG90微型舵机 | 1（每条腿） | 微型——仅提供微小调整，不承重 |
| 肩关节 | MG996R | 2（每条手臂） | 一个水平旋转（肩关节水平外展）、一个垂直（肩关节前屈/后伸） |
| 肘关节 | MG996R | 1（每条手臂） | 单轴屈伸 |
| 腕关节 | SG90微型舵机 | 1（每条手臂） | 微型，控制夹具开合 |

**说明：**
- 下肢使用LX-16A（扭矩约15kg·cm，响应速度快且带角度反馈）是因为承重——40cm机器人在站立时每条腿要承受约一半体重（约250g放大到关节处的杠杆载荷非常可观）
- 上肢使用MG996R（约9.4kg·cm）足够了——手臂不承重，只负责抓取轻量物体（水瓶<500g）
- 所有舵机都有一定的回差（backlash），这在软件上通过补偿来处理

### 结构材料

- **主体骨架**：白色PLA（聚乳酸）FDM 3D打印，层高0.2mm。PLA是一种成本最低（约30元/kg）、最容易打印的3D打印材料，但缺点是脆、不耐冲击、热变形温度低（~60℃）
- **关节连接件**：M3不锈钢螺丝（标准件，便宜好买）+ 内嵌黄铜螺纹嵌件（加热熔入PLA）

### 动力与控制

- **主控制器**：STM32F407VET6（或F405最小系统板）——150元左右的Cortex-M4F处理器，足够做12个舵机的PWM/串口控制和姿态解算
- **IMU**：MPU6050（六轴加速度+陀螺仪，约15元），用于检测倾角——V0.1的站姿仍然前倾就是这个IMU的融合算法还没调好的表现
- **电源**：2S LiPo（7.4V）通过降压模块分两路供电——5V给舵机、3.3V给控制器
- **视觉/雷达**：V0.1阶段未安装——手部动作由预设轨迹控制（记录下的力学轨迹），而非实时视觉引导

### 布线方式

- 所有导线沿着骨架表面走，用热熔胶+扎带固定——这是大学生做机器人的典型风格
- 不同电压的导线（信号线/电源线）用不同颜色区分：红色→5V舵机电源、黑色→GND、彩色（黄/白/蓝）→PWM/串口信号线
- JST-XH插头连接每一种舵机，方便拆卸

### 外观特征

- 不涂装，PLA原始灰白色，层纹可见
- 头部是一个简化的球体（直径约4cm），无面部特征——只有两个小的圆形孔（预留传感器安装位）
- 螺丝头外露，部分关节处有热熔胶加固的痕迹
- 整体视觉：**"一个认真的大学生在宿舍和实验室里做了一年能做出来的东西"**

## 8 小七 V0.3（研三·农田版）

### V0.1→V0.3 设计变更

| 项目 | V0.1 | V0.3 | 变更原因 |
|------|------|------|---------|
| 骨架材料 | PLA | PETG（部分）+ PLA | PETG强度高、耐冲击、65℃热变形——农田可能需要暴晒 |
| 外壳 | 无 | 浅灰色PETG半壳覆盖躯干正面 | 保护电子元器件免于尘土和水溅 |
| 头部 | 无传感器 | 安装YDLIDAR X4激光雷达 | 农田地形感知和障碍物避让 |
| 手臂腕关节 | 1-DOF | 增加1个SG90做中间自由度 | 提高抓取姿态灵活性——摘豆角需要不同手部角度 |
| 足端 | 裸PLA | 加装硅胶防滑垫 | 在泥土和湿地面上不打滑 |
| 背部 | 空 | 加装3D打印储物槽 | 运送种子或采摘的少量果实 |
| 手爪内侧 | 薄橡胶 | 加厚硅胶垫+压力感应贴片 | 摘西红柿不能捏伤，需要反馈力控制 |
| 防水 | 无 | 关节处加3D打印波纹防尘套 | 农田有尘土、露水、小雨 |
| 充电口 | 裸露排针 | 加装橡胶防水塞 | 户外使用 |
| 电池 | 2S 500mAh LiPo | 2S 1500mAh LiPo（更大容量硬壳电池） | 延长田间工作时间 |

### 新增硬件

- **激光雷达**：YDLIDAR X4（12米测距，约600元，USB接口），安装在头部前方，作为主导航传感器
- **摄像头**：USB免驱摄像头（~100元），用于视觉识别——通过Nano运行小熊提供的开源视觉模型（TensorRT优化）
- **视觉处理器**：Jetson Nano（约800元），加装在背部储物槽下方——负责运行作物视觉模型和成熟度判定
- **土壤传感器接收模块**：nRF24L01 2.4G无线模块（~30元），与田间的土壤传感器节点通信

### 外壳设计

- 浅灰色PETG打印的半封闭外壳——只覆盖了躯干正面和侧面，背部是裸露的（为了散热和走线）
- 外壳表面经过打磨（用砂纸打了一遍）但仍然能看到层纹——不是一个注塑件
- 躯干左侧角落有黑色马克笔手写的"小七"标签（第10集写上去的，第12集回到老家时还在）

### 接线方式变化

- 导线增加了热缩管保护（每个焊点处）——不再是裸线
- 使用了螺旋电缆管（在五金店能买到的那种黑色塑料螺旋管）整理线束
- 每个连接处涂了一滴703硅胶做防水——这是学生能想到的最简单的户外防水做法

## 9 小七 V2.0（毕业后·量产版）

### 与V0.3的根本差异
V2.0不是林一鸣一个人做的了——它是"一鸣智能科技"团队（赵建平+王海燕+IronHand远程）做出来的。所以它**不是手工品的升级版，是初代工程样机**。

### 尺寸
**与V0.1/V0.3相同：约40cm高**。保持尺寸不变有三个原因：
1. **观众辨识度**——观众要能在三秒内认出"这是小七"
2. **零件复用**——部分结构可以沿用电机的选型，减少重新设计
3. **剧情设定**——第一代产品从桌面级开始，符合创业团队的现实选择

### 机械结构变化

| 层级 | V0.3 | V2.0 |
|------|------|------|
| 外壳 | PETG半壳（3D打印） | ABS注塑全壳（开模）——表面哑光处理，无层纹 |
| 减速方式 | 舵机自带塑料齿轮 | 行星减速器+小型直流无刷电机（BLDC）——来自IronHand渠道 |
| 关节精度 | 舵机回差不可控 | 编码器闭环——每个关节电机带2048线磁性编码器 |
| 手爪 | 二指平行夹具 | 三指欠驱动手（通过连杆结构使三个手指自适应包裹物体形状） |
| 腿部 | PLA+PETG打印 | ABS注塑内骨骼+外壳覆盖 |
| 足底 | 硅胶垫 | 集成了力传感器的弹性足底 |

**技术合理性说明**：
- V2.0的电机方案来自于**IronHand前公司剩余的非标电机模组**（不是全新开发——作为创业公司使用现成模组合理）
- 三指欠驱动手是一个经典的机器人设计——不需要复杂的控制算法，一根弹簧+连杆结构就能自适应抓取不同形状的物体。很多大学实验室自己做的手爪都用这个方案
- 外壳开ABS注塑模对于一个拿到了融资的创业公司是合理的起步投入

### 外观设计

- **主色调**：白色（Pantone类似色），哑光表面，不反光
- **第二色**：浅灰色（关节波纹管外壳和传感器区域）
- **表面处理**：无可见螺丝（所有螺丝都被外壳盖住了）——第一次看起来像"一件完整的产品"
- **头部设计**：有了"面部区域"的轮廓暗示——两个椭圆形的黑色视觉传感器窗口（位置和间距像"眼睛"），中间下方有一个窄条状的麦克风阵列开口（像"嘴"）。它不是人脸，但让人感觉到"这是一个有正面和背面的东西"
- **品牌标识**：胸前有激光雕刻的公司Logo（一个简单的"M"和"7"组合——"一鸣"和"小七"）
- **充电**：无线充电线圈内置（只需要一个充电底座）

## 10 外骨骼机器人（给母亲）

> 设计原则：**这不是一个科幻外骨骼。这是一个学生用自己做的电机+碳纤维管+3D打印关节拼出来的康复设备。** 
> 功能目标：帮助因长期缺乏运动导致下肢肌萎缩的患者重新站立和短距离行走。

### 整体结构

```
      [ 腰部绑带+控制器 ]
           ╱    ╲
     [髋关节电机] [髋关节电机]
          │         │
     [大腿碳纤维管] [大腿碳纤维管]
          │         │
     [膝关节电机] [膝关节电机]
          │         │
     [小腿碳纤维管] [小腿碳纤维管]
          │         │
     [踝关节被动弹簧] [踝关节被动弹簧]
          │         │
     [可调节脚套] [可调节脚套]
```

### 关节配置与可行性

| 关节 | 类型 | 电机来源 | 说明 |
|------|------|---------|------|
| 髋关节（左右各一） | 主动——小型BLDC+行星减速器 | IronHand寄的XX-12电机（第15集） | 提供站立和坐下时的主要扭矩输出——约20-30Nm（通过减速器放大） |
| 膝关节（左右各一） | 主动——同上 | 同上 | 锁死时承担全部体重——需要一个电磁刹车防止断电时突然失力（使用自行车碟刹的电磁铁改造） |
| 踝关节（左右各一） | 被动弹簧辅助 | 无电机 | 提供减震和植屈/背屈的被动跟随——硬质弹簧+旋转电位器检测角度 |

**技术说明**：
- 第15集林一鸣在供应商目录角落找到了库存型号XX-12，这也是IronHand确认过的扭矩密度接近的方案。电机只有四台（以后需要两台）——原因是"有人批量下单包了库存"（仓库电话那场戏）
- 两台电机+两台电磁刹车可以做到一个功能完整的**单腿验证系统**。但林一鸣需要双腿同时工作才能让母亲走路——所以他后来要重新找替代供应商（第16集外骨骼测试失败时第四盏灯不亮，就是膝关节电机出了问题）

### 结构材料

- **骨架**：碳纤维管（12mm外径，黑色编织纹路）——在淘宝上能买到，几十块一米。重量轻、强度高，适合做外骨骼骨架
- **关节外壳**：3D打印PETG——黑色，层纹可见。暂时没有加工金属件的能力
- **绑带**：宽尼龙绑带+魔术贴——医用外骨骼的常见绑缚方式，来自运动护具或登山扣的改造
- **关节连接件**：M4不锈钢螺丝+铝合金L型角码——五金店里能买到的标准件

### 控制系统

- **控制器**：在腰部外侧的小黑盒子里——继续用STM32F4系列（林一鸣最熟悉的平台）
- **传感器**：膝关节角度编码器+足底压力传感器+IMU（检测人的运动意图——当检测到身体前倾时判断"想站起来"，膝关节电机配合出力）
- **电源**：腰部绑带上的2S LiPo电池包（18650电芯×2+充电保护板）——用防水布包着，绑在腰后
- **用户交互**：4个LED指示灯——电池电量×1、左腿状态×1、右腿状态×1、系统错误×1

### 操作方式

杨秀兰穿上外骨骼后，第一件事是**扶着桌子**站起来——不是因为外骨骼没力气，是因为她太久没有站立了，**心理上需要一个支撑**。电机出力是在检测到她的意图后才启动的——这不是"外骨骼自己站起来"，是"外骨骼配合她站起来"。

这个细节在剧中很重要：第17集她站起来时的第一个动作是看自己腿的高度——她的视觉高度已经很多年没有在这个视野位置看到这个家了。

### 外观特征

- **整体都是黑色的**——碳纤维管黑色、3D打印关节黑色、绑带黑色、控制盒黑色。只有关节处的金属件是银色的
- **它不是"穿戴在身上"的——它是"绑在身上的"**。外观上可以看出绑带、魔术贴、调节扣
- **不是好看的——是能用的**。这个区别是它最重要的视觉特征
