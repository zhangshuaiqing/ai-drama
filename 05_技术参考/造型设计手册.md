# 《麦田里的钢铁》—— 角色与机器人造型设计手册

> 版本：V1.0 | 日期：2026-05-22
> 用途：AI生成（文生图/图生视频）角色一致性参考、演员选角参考、3D建模参考

---

## 设计原则

1. **写实为主**：不过度美化或戏剧化——农村就是农村，学生就是学生，老师就是老师
2. **时间线可辨识**：三个时间阶段（童年/大学/硕博）之间有明确但自然的视觉变化
3. **服装反映人物**：林一鸣的服装从"有啥穿啥"到"随便穿"到"稍微注意一下"的演变
4. **小七的进化**：从裸骨架到外壳安装到完整产品，每一版都有可见的技术进步

## 1 林一鸣（男主）—— 贯穿全剧的核心人物

### 【阶段一：童年 14岁】

| 维度 | 描述 |
|------|------|
| **脸型** | 瘦长脸，颧骨微高，还没长开。脸上有晒斑。眼睛大但习惯眯着（农村孩子怕眯眼？不，是太阳底下看远处养成的习惯）。眉毛浓但还没成型，眉型有些杂乱。嘴唇薄，容易干裂。 |
| **肤色** | 黝黑偏棕——夏天在地里晒出来的，不是天生的深肤色。脖子后面最黑，耳朵后有一块白——那是衣服领子遮住的地方。 |
| **头发** | 农村常见的板寸——便宜、不用打理。发质偏硬，剪得不太整齐（村口理发店的手艺）。 |
| **手** | 手掌有薄茧——不是干重活磨出来的厚茧，是干零碎农活和做玩具磨出来的。手指细长但有力。指甲缝里经常有泥。 |
| **体型** | 瘦小精瘦，没多少肉，但也不是营养不良——是消耗量大于摄入量的那种瘦。肩膀窄，脖子细。肋骨隐约可见。 |
| **服装** | 白色旧背心（洗到发黄了）或光膀子。深色短裤，长到膝盖上面一点，裤脚磨破了。光脚或者穿一双大了一码的解放鞋。 |
| **标志性道具** | 一把自己做的小弹弓（握柄磨得发亮）、一块画着人形草图的木板、一把断弦的弓 |
| **AI人物造型提示词** | A 14-year-old thin Chinese boy from rural Shandong, sun-tanned skin, high cheekbones, slightly messy crew cut hair, wearing an old white tank top and dark shorts, barefoot or worn canvas shoes. Lean build, visible ribs. Cracked lips, dark tan line on neck. Has a homemade slingshot with worn handle. Realistic portrait, natural daylight, photorealistic. |

### 【阶段二：大学 18-22岁】

| 维度 | 描述 |
|------|------|
| **脸型** | 比童年时棱角分明了——下颌线出来了，颧骨没那么突了。眉毛定型了——粗而直，不修。眼神比同龄人沉——不是发呆，是在想事情。偶尔有黑眼圈（熬夜调机器人）。嘴角平时是平的，不笑的时候看起来有点严肃。 |
| **肤色** | 比童年白了（大部分时间在教室和实验室），但比一般大学生黑一点。手臂外侧和脸还是偏深——偶尔回家干活的痕迹。 |
| **头发** | 依然是板寸，但比童年整齐了一点（学校旁边理发店10块钱的剪法）。发旋在头顶偏右。 |
| **手** | 开始出现新的痕迹——右手食指和中指之间有一个小小的烙铁烫伤疤（焊东西时烫的）。掌心有焊锡的细小黑点。左手食指有刀片划伤的老疤。 |
| **体型** | 175cm左右，偏瘦但结实。长期坐着脊柱有点前倾，但走路时看不出来。肩膀比童年宽了一些。 |
| **标准服装组合A** | 洗得发白的蓝色格纹长袖衬衫，袖子卷到小臂中段。领口扣子解到第二颗。内搭深灰色或白色T恤。深蓝色牛仔裤（膝盖处有轻微磨损）。一双穿了一年的运动鞋。 |
| **标准服装组合B** | 深色卫衣或深蓝色T恤。同样的牛仔裤和运动鞋。冬天加一件旧外套（可能是父亲淘汰的军绿色夹克）。 |
| **实验室着装** | 格纹衬衫不扣——当外套穿，露出里面的T恤。袖口卷得更高——到肘弯以上。深色长裤或深灰色工装裤。 |
| **标志性道具** | 四足机器人、STM32F4开发板、旧笔记本（写满代码和草稿）、铁牛一号遥控器（比赛专用） |
| **发型细节** | 板寸，两侧和后脑勺剪得比较短，顶部留约3厘米。洗完头不用吹风机，自然干。 |
| **AI人物造型提示词** | A 20-year-old Chinese male university student, engineering major, lean build about 175cm. Short neat hair. Square jaw beginning to form, thick eyebrows, focused eyes, mild dark circles from staying up late. Wearing a faded blue plaid long-sleeve shirt with sleeves rolled to mid-forearm, dark jeans, worn sneakers. Has a small soldering burn scar between right index and middle finger. Looks like he's thinking about something even when resting. Natural dorm lighting, photorealistic portrait. |

### 【阶段三：研究生 23-25岁】

| 维度 | 描述 |
|------|------|
| **脸型** | 完全张开了——大学时的少年感褪去，变成一个成年男人的轮廓。眼袋比大学时明显——这几年熬的夜。眼神比之前更深——不是更累了，是更定了。偶尔有胡茬（刮得不勤，但也不是故意留的）。 |
| **肤色** | 介于大学和童年之间——长时间在实验室，但偶尔回老家田里干活。 |
| **头发** | 头发比大学稍微留长了一点——不再严格板寸，头顶约4-5厘米。发质硬，有时候起来会翘。 |
| **手** | 大学时的手上的痕迹还在，更多了——多了几个新的焊疤。手指比以前更有力了——拧螺丝拧出来的。 |
| **体型** | 与大学时差不多，但肩膀又宽了一点。坐姿仍然前倾。 |
| **标准服装** | 深色夹克或外套（深蓝或深灰），内搭浅色T恤。深色卡其裤或工装裤。换了一双更实用的工装靴。 |
| **公司阶段（后几集）** | 同样风格但不那么旧了——深色衬衫，没有领带，整洁但不好看。口袋里常揣着一支笔和一本小笔记本。 |
| **标志性道具** | 小七（贯穿）、灰色的图纸筒、旧笔记本（"外骨骼"）、外骨骼测试用的一次性组件 |
| **AI人物造型提示词** | A 24-year-old Chinese male graduate student / startup founder, lean athletic build about 175cm. More mature face than university years, visible under-eye bags, occasional stubble. Hair slightly longer than crew cut. Wearing dark jacket over light t-shirt, dark work pants, practical boots. Focused eyes of someone who spends long nights in a lab. Holds a notebook with mechanical sketches. Natural lighting, photorealistic. |

## 2 林建国（父亲）

| 维度 | 描述 |
|------|------|
| **脸型** | 标准的山东农民长相——宽脸，颧骨高，下颌宽。五官端正但被劳动改变了——眼角的皱纹不是因为笑多，是因为眯眼看远处的田。额头上有横向的抬头纹。法令纹深。 |
| **肤色** | 棕黑——常年在地里晒的。脸、前臂、小腿是同一个颜色。被衣服遮住的地方浅两个色号。 |
| **头发** | 花白短发——不是自然灰白的，是黑发和白发混在一起的那种。头发硬，根根竖起。头发剪得很短，自己对着镜子剪的那种感觉。 |
| **手** | 整个剧里最重要的视觉符号之一。宽大，粗糙，手指关节粗大，手掌布满深色的裂纹（泥土嵌在裂缝里洗不干净）。指甲扁而宽，甲床比一般人短（长期干农活把指甲磨短了）。手背上有几个深色的老年斑（虽然他才40多岁——是日照造成的）。 |
| **体型** | 中等偏瘦，但肩膀宽。因为长期干重活，他的体型不是健身房那种——是实用的力量：背部厚，手臂不粗但有力，腿肌肉结实。走路微带罗圈腿（常年在地垄上走踩出来的）。 |
| **服装** | 褪色的蓝色或灰色布衫，领口磨破了。解放鞋——鞋面上经常沾着泥。腰间拴着一串钥匙和一个旧打火机。夏天穿短袖时露出晒成两截颜色的手臂。秋冬加一件军绿色旧外套——不知道穿了几年了。 |
| **标志性姿态** | 蹲在门槛上抽烟——农村男人特有的蹲法，脚跟踮地，双膝分开，一只手搭在膝盖上，另一只手夹烟。说话前先吸一口烟。 |
| **AI人物造型提示词** | A 46-year-old Chinese farmer from Shandong, broad face with deep wrinkles, dark sun-baked skin. Short graying hair standing up. Wide calloused hands with deep cracks. Wearing faded blue work shirt and canvas shoes, a string of keys hanging from his waist. Slight bow-leg stance from walking on field ridges. Calm eyes, speaks little. Squatting on a doorstep smoking a cigarette. Photorealistic rural portrait, natural outdoor light. |

## 3 杨秀兰（母亲）

| 维度 | 描述 |
|------|------|
| **脸型** | 清瘦的脸，五官端正。因为长期生病坐着，脸比同龄农村妇女白一些——没有被太阳晒到。眼睛是温柔的，跟林一鸣很像——他的眼睛就是遗传了她的。嘴角平时微垂，看儿子时会自然地上扬。 |
| **肤色** | 偏白——因为长期在家或坐着，不是那种苍白的白色，是没晒到太阳的自然肤色。脸颊上有一点淡淡的雀斑（年轻时的回忆）。 |
| **头发** | 到肩膀的中长发，用普通的黑色发圈扎成低马尾。额前有几缕碎发。头发中已经有了一些白发——比同龄人稍多（病的缘故）。清秀但不清淡，有一种安静的美。 |
| **手** | 手指修长，骨节分明。不做重活，但做手工和家务——手掌有薄茧。给林一鸣涂碘伏的那双手——动作很轻很稳。 |
| **体型** | 清瘦。长期坐轮椅，肩膀比正常状态略宽（手臂支撑负重的结果）。穿着家常的碎花布衫，腿上盖着一条旧薄毯——不管冬天夏天都盖着（腿部血液循环不好）。 |
| **服装** | 干净朴素的农村妇女穿着——碎花布衫或浅色衬衫，深色长裤，腿上盖毯子。不是旧得发苦那种，是干净但朴素的。秋冬加一件手工编织的毛背心。 |
| **关键动作** | 伸手摸儿子的脸——这个动作在剧中出现好几次，每次含义不同。第一次是心疼，最后一次是骄傲。 |
| **AI人物造型提示词** | A 42-year-old rural Chinese woman from Shandong, sitting in a wheelchair. Thin face, gentle eyes that look like her son's. Light complexion from staying indoors. Hair in a simple low ponytail with some graying strands. Wearing a neat printed blouse, dark pants, a thin blanket over her lap. Delicate hands — she once made things too. Warm maternal expression. Indoor lighting, soft natural light from window. Photorealistic. |

## 4 苏晚晴（初恋）

| 维度 | 描述 |
|------|------|
| **脸型** | 五官端正，属于耐看型——第一眼不会惊艳，但越看越舒服。眉毛不浓不淡，自然地弯着。眼睛不大但笑起来会眯成一条缝。整体气质亲切温暖。 |
| **肤色** | 正常中国大学生的肤色——不白也不黑，不刻意防晒也不故意晒。脸颊有一点自然的红润。 |
| **头发** | **大学时期：** 清爽的短发——长度到耳下，不烫不染，自然黑发。额前有轻薄的空气刘海。发质柔顺，不需要特别打理。<br>**工作后：** 稍微长了一点——到肩膀位置。扎起来或者披着看心情。发型更成熟了，但仍然保持自然的黑色。 |
| **体型** | 165cm左右，正常偏瘦。不胖不瘦，站姿端正（有税务局的工作气质后更明显）。 |
| **服装** | **大学时期：** 浅色外套（米白或淡粉色），白色T恤，深蓝色或浅色牛仔裤。一双白色帆布鞋。简单干净，不刻意打扮。<br>**工作后：** 稍微正式一点——白色衬衫，深色长裤，低跟单鞋。外搭一件浅色风衣。不再是学生打扮了。 |
| **与林一鸣的关系视觉提示** | 两人站在一起时她矮半个头，跟他说话时微微仰头。她笑起来眼睛弯——这个特征在第3集体育馆门口初见时和第4集送伞时都要一致。 |
| **AI人物造型提示词** | A 20-year-old Chinese female university student, 165cm. Short clean black hair above shoulders, light bangs. Pleasant and approachable face that becomes warmer when she smiles — eyes naturally crescent. Fair complexion with slight blush. Wearing light colored jacket over white t-shirt, blue jeans, white canvas shoes. Natural, not trying too hard with appearance. Friendly warm expression. Portrait, natural daylight, photorealistic. |

## 5 顾知夏（最终伴侣）

| 维度 | 描述 |
|------|------|
| **脸型** | 偏长脸，眉目清秀，看起来比实际年龄干练。不是说她长得老——是她有一种"不太在意自己好不好看"的气质。五官整齐，不化浓妆，但皮肤保养得很好。 |

| **头发** | 齐肩的中长发，经常扎成低马尾或半扎。发色自然黑，质感好——不是刻意的那层，是本身就顺。不做美甲。 |
| **体型** | 170cm左右——比苏晚晴高一些。身形挺直——不是站军姿那种，是自然而然的自信站姿。 |

Confident forward posture — not stiff but self-assured. Well-fitted white blouse, dark tailored pants, practical low-heel shoes. Not conventionally "pretty" in a polished way — but strikingly competent in expression. Standing with a slight tilt of the head, as if listening closely. Office background, natural lighting, photorealistic. |

## 7 小七 V0.1（研二·原型机）

| 维度 | 描述 |
|------|------|
| **尺寸** | 约40cm高——桌面级人形机器人原型 |
| **材料** | 白色/浅灰色PLA 3D打印骨架。骨架裸露——没有外壳，可以看到内部的电机、导线和减速器。这是一种"还在设计中"的视觉感。 |
| **躯干** | 扁平的长方体躯干，内部中空，用来容纳控制器和电池。表面有散热开槽。 |
| **头部** | 一个简化的球体——没有面部表情，没有五官。头顶预留了传感器安装位（一个圆形的凹槽）。它不是"脸"——它是一个"传感器的位置"的提示。 |
| **手臂** | 每边4个关节（肩×2+肘×1+腕×1）：3D打印的管状上臂和前臂，各种颜色的导线沿着骨架表面走。末端执行器是一个简单的两指平行夹具，内侧贴了薄橡胶——增加摩擦。 |
| **腿部** | 每边5个关节（髋×2+膝×1+踝×2）。大腿和小腿的PLA结构比手臂粗两倍——需要承担重量。 |
| **表面处理** | 未涂装——PLA的原始灰白色。层纹可见。螺丝头外露。有些关节处有胶水痕迹。 |
