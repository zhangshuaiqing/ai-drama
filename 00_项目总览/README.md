## 项目概述

一部16集青春励志/科技热血/乡土情怀短剧（每集20分钟）。讲述一个从农村走出来的自动化专业学生，从童年在地头补种时产生"为什么机器到不了的地方还得人弯腰"的疑问开始，经过大学时期的偏科与坚持、考研调剂的低谷、硕士期间在导师支持下重建实验室、在发烧友群中吸收各路技术精华，最终造出通用人形机器人"小七"，并将其应用于农业、家政、养老、巡检等多个领域的故事。

全剧采用三幕剧结构，电影级别的叙事节奏，人物刻画细腻，情感铺垫充分。

## 核心设定一句话

> **"他造的机器人，能插秧，能摘果，还能叫一声'妈'。"**

一个农村出身的孩子，因为深知体力劳动的苦，立志用机器人解放人的劳动。童年看《我爱发明》自己动手做玩具，考取省属普通理工院校，本科自学编程、机械建模、电路设计，全国机器人大赛团队获奖（他是技术核心）。因绩点不够保研，考研调剂普通院校读研。母亲的病残和初恋的离开成为他心里的刺。在导师支持和"机器人杂货铺"网上社群各路发烧友的帮助下，他做出人形机器人"小七"，并为母亲制作外骨骼机器人。之后将技术应用于农业，搭建智能化农场，政府推广全镇。

## 创作讨论记录

### 初始素材（用户提供）

- 主角：刚毕业的硕士，自动化专业
- 核心成就：制作了超越当前最高智能水平的人形机器人
- 背景故事：童年看《我爱发明》自己动手做玩具 → 本科自学编程/机械/电路 → 机器人大赛团队奖（技术核心非队长） → 绩点不够保研 → 考研调剂普通院校 → 硕士期间钻研技术 → 导师资金支持 → "机器人杂货铺"发烧友群 → 母亲因病致残，做外骨骼机器人
- 制作动机：出生于农村，儿时从事农活，看到父母辛苦
- 附加成果：制作各种农用机器 + 智能化农场 + 政府推广
- 机器人特点：能与各种农用机器通信协同，适应非标准化流程
