# 第六轮审查 —— 剧本自身问题的优化建议

> 评审日期：2026-05-22
> 本次聚焦：剧本自身的问题，不重复之前已提过的修复建议

---

## 问题一：第1集 vs 第2集——林一鸣画外音语气不一致

### 问题描述

第1集画外音语气**冷静、克制、带一点自嘲的平静**（"新麦子水分大，堆在一起两天就发霉了"、"一年忙到头，就这些"——只陈述事实，不抒情）。第2集画外音语气更**直接、朴实、带一点"愣"**（"我大一的时候还不知道自己想要什么"、"有些课听一遍就会了"）。

两种语气单独看都没问题，但出现在同一个人物的画外音中，会让观众隐约觉得"说话的不是同一个人"。

### 优化方案

中年林一鸣的画外音应该保持统一的语气基底——**平静地陈述，不带情绪地回忆**。第2集中需要调整的画外音：

**第2集 场1 画外音：**
> 原：「"我考上大学那年，村里人问我考上了哪个学校。我说了个名字，没人听过。我爸说，'没事，能读书就行。'我当时也没觉得学校大小有什么重要——有实验室就行。"」
> 
> 建议改为：「"考上大学那年，村里人问考上了哪个学校。我说了个名字，没人听过。我爸说，没事，能读书就行。"」

**调整幅度**：删去"我当时也没觉得学校大小有什么重要——有实验室就行"这句。因为：
1. "我当时"是典型的第一人称回忆视角，与第1集画外音保持的距离感不一致
2. "有实验室就行"这个判断在第1集结尾已经有了更完整的表达（"学校高不高、大不大，跟你能做出什么东西——没有关系"），不需要在第2集提前cue

**第2集 场7 画外音：**
> 原：「"那个帖子我看了好几遍。写得真好。作者是个汽修厂的电工——这是后来我才知道的。在网上，没有人管你是大学生还是电工。你贴出来的东西对，大家就服你。"」
> 
> 建议改为：「"那个帖子我看了好几遍。写得真好。后来才知道作者是个汽修厂的电工。在网上，没有人管你是大学生还是电工。"」

**调整幅度**：删去"你贴出来的东西对，大家就服你"。这句也是结论式的"过去我在想什么"，与中年回忆的距离感不匹配。让画面自行说话。

**不需要改动（保持原样）的画外音：**
- 第2集 场5「"我想让它走稳"」——这是年轻林一鸣的现场对话，不归画外音管，没问题
- 第2集 场9「"那是我大学期间做的第一个被老师说'不错'的东西……"」——语气与第1集一致，保留

## 问题二：第2集场5——刘洋追问过多

### 问题描述

刘洋三连问：

> Q1：「一鸣，你那个玩意儿能当饭吃吗？」
> Q2：「那你弄它干啥？」
> Q3：「走稳了能干啥？」

三问在节奏上形成"逼问感"。第三问让刘洋从"爱开玩笑的室友"变成了"代表普通人对主角提出质疑的工具人"。

### 优化方案

**删去Q3（"走稳了能干啥"），保留Q1+Q2。**

保留Q1制造氛围（室友关心他在搞什么），保留Q2引出林一鸣的答案（"我想让它走稳"）。删掉Q3是因为林一鸣已经在Q2的回答中完成了角色表达（"不知道。但我想看看它走稳了之后，是什么样"），再逼一次就过了。

**修改后：**

```
刘洋（从上铺探出头，耳机摘下一只）：
> 一鸣，你那个玩意儿能当饭吃吗？

林一鸣（没抬头，继续敲键盘）：
> 现在不能。

刘洋：
> 那你弄它干啥？

林一鸣这一次没有马上回答。他看着桌上那个歪歪扭扭的四足机器人——它的四条腿还在微微抖动，像是随时要站起来，又像随时要倒下去。

林一鸣：
> 不知道。但我想看看它走稳了之后，是什么样。

刘洋（没再问了，戴上耳机之前说了一句）：
> 行吧。你要是把它弄会走路了，告诉我一声。

林一鸣没回答，但嘴角动了一下。
```

Q3删除后，刘洋的追问从"质疑"变为"好奇"，角色关系更自然。

## 问题三：第1集与第5集——调剂入学路径重复

### 问题描述

第1集最后3场：走进XX工业大学校门 → 宿舍建Project-Humanoid文件夹 → 天亮。
第5集全篇：离开本科宿舍 → 回家 → 菜地摘豆角 → 村口坐公交 → 走进XX工业大学校门 → 宿舍建Project-Humanoid文件夹 → 天亮。

第5集是第1集"调剂入学"的**完整展开版本**。但观众连续观看时，在第1集已经经历过"走进校门→建文件夹"的收尾，到第5集再次经历同样的情感节点——且第5集花了全篇篇幅走完同一个流程——会产生重复感或节奏拖沓感。

### 优化方案

**方案A（推荐）：第1和第5集的"建文件夹"做差异化处理**

第1集建文件夹时强调**"这是开始"**的感觉——新鲜的、充满希望的。

第5集建文件夹时强调**"这是完成"**的感觉——经历了整个夏天的人终于走到了这一步。

具体修改：

**第1集 场11（建文件夹）：**
保留当前版本。功能是"他开始了"。

**第5集 场9（建文件夹）：**
加一个第1集没有的细节——他在建Project-Humanoid之前，先把本科期间所有资料拖进了一个旧文件夹叫"archive"，然后才建新的。这个动作的潜台词是：把过去四年打包放好，然后从头开始。

```
他打开笔记本电脑。
先建了一个文件夹，取名"archive"。
把桌面上的课程、论文、开源项目——本科四年攒的所有东西——拖了进去。

然后他建了一个新文件夹。
光标闪烁。
输入名字：Project-Humanoid

他靠在椅背上，看着屏幕上那个文件夹。
和那个夏天的开始不一样——现在他知道自己要做什么了。
```

**方案B（备选）：第1集结尾只到考研出分，不写到调剂入学**

第1集停在林一鸣看到考研成绩那一夜（场9），不往下走。第5集从头到调剂入学。第1集结尾的台词还是"别想了，吃饭"——温暖、克制、收住。但这样改动较大，且第1集目前以建文件夹+"小七——第一步"做收尾效果很好，不太建议动。

**推荐方案A**，改动最小，效果好。

## 问题四：第2集场4（图书馆）信息量偏低

### 问题描述

图书馆一场的核心功能是展示"他在自学机器人学，不务正业"——但这个功能已经被场3（高数课上画电路图）覆盖了。场4多了一个"对面的女同学看了他一眼"的细节，但这位女同学在后续剧本中没有任何作用，看起来像是一个被废弃的角色设定。

### 优化方案

有三种处理方式：

**方案A（推荐）：将对面女同学改为后续有名字的角色**

如果这位女同学不是没用的细节，直接删掉整场。删除后不影响第2集的叙事流。

**方案B：把图书馆场景的功能升级**

不删除，但把"对面女同学看了他一眼"改成一个更有叙事牵引力的细节。例如：

```
对面坐着一个女同学，看了他一眼——这个人面前没有课本，没有复习资料，只有一本旧书和一堆公式推导。

她没说什么。走的时候，在他桌上放了一张纸条：
"你是机器人协会的吗？我们缺一个搞控制的。"

她走了。林一鸣拿起纸条看了看，没当回事，把纸条夹进书里了。
```

这条纸条可以在未来某个节点被触发（比如他后来真的去了那人的项目），也可以只是一个"伏笔感"的细节，让观众记得有人在找他。

**方案C：删除场4，将功能合并到场3**

对场3高数课的描述加一行——

```
他的笔记本：前半部分是课堂笔记（工整的），后半部分开始出现舵机控制时序图、PWM波形示意、以及一行字——"为什么不用三段式PID？"

旁边还放着一本从二手书店买的《机器人学导论》，书脊已经翻白了。
```

删去整个场4（图书馆），让第2集更紧凑。

## 问题五（新增）：第2集场10——ZMP问题提问后缺少"被看见"的情感落点

### 问题描述

第2集结尾：他发了一条向IronHand请教ZMP的提问，点击发送，切黑屏。片尾彩蛋中IronHand回复了。但是**正片结尾没有一个情感落点**——观众看到的是"他问了一个问题，然后就没了"。

相比第1集结尾（建文件夹+"小七——第一步"的笔迹），第2集结尾的叙事推力偏弱。

### 优化方案

在发完问题后，加一个短暂的画面——

```
他鼠标停在"发送"按钮上。停了两秒。

他点了发送。

然后他靠在椅背上，看着屏幕。
屏幕的光照在他脸上。他等了一会儿——不是期待立刻收到回复——就是等了一下。

然后他关掉页面，拿起旁边的四足机器人，翻过来，检查了一下关节的螺丝。
```

加这一行的目的：不是所有人都发完帖子就回去睡觉。他发完之后还会再看一眼机器人，因为他还在那个世界里。
