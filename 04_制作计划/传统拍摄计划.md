### 阶段1：剧本开发（4-8周）

#### 1.1 最终决策会（0.5周）

| 任务 | 说明 |
|------|------|
| 确认所有"创作岔路口"的最终选择 | 剧名、IronHand身份、母亲线处理、感情线走向、结尾方式 |
| 确认剧集数 | 8集是否合适，或压缩/扩展 |
| 确认技术顾问 | 是否需要专业人士审核技术细节 |
| 确认目标受众和发布平台 | 决定剧本的尺度和节奏 |

#### 1.2 分集剧本写作（3-6周）

| 阶段 | 内容 | 建议周期 |
|------|------|---------|
| 第2-3集剧本 | 实验室、论坛、技术攻关线 | 1-2周 |
| 第4集剧本 | 小七觉醒（剧本高潮之一） | 1周 |
| 第5-6集剧本 | 回家、农田、推广大使（乡土线高潮） | 1-2周 |
| 第7-8集剧本 | 资本交锋、结局升华（全剧高潮） | 1-2周 |
| 全剧统稿 | 一致性检查、台词打磨、节奏调整 | 0.5周 |

**注意**：第4集（小七觉醒）和最后一集（结局）是全剧最重要的两个节点，建议额外打磨。

#### 1.3 剧本评审与修订（1周）

| 任务 | 说明 |
|------|------|
| 内部通读 | 团队一起朗读全剧剧本，检查台词是否自然 |
| 技术顾问审查 | 确认技术术语、场景是否合理 |
| 制片人评审 | 检查每个场景的拍摄可行性 |
| 定稿 | 剧本冻结，进入下一阶段 |

**本阶段完成标志**：剧本定稿，每一场戏的台词、动作、场景描述都已锁定。

### 阶段2：前期制作 / 预生产（4-6周）

#### 2.1 团队组建（并行）

| 角色 | 说明 | 优先级 |
|------|------|--------|
| 导演 | 总负责视觉实现（如果制作人自己不导，需要聘请） | 必需 |
| 摄影指导 | 负责画面效果、镜头语言 | 必需 |
| 美术指导 | 负责场景、道具、色彩方案 | 必需 |
| 录音师 | 现场收音 | 必需 |
| 灯光师 | 布光方案 | 必需 |
| 服化道 | 服装、化妆、道具管理 | 视预算 |
| 后期剪辑 | 可提前介入 | 建议提前沟通 |

#### 2.2 分镜头脚本（2-3周）

| 任务 | 说明 |
|------|------|
| 剧本拆解 | 将文字剧本拆为逐镜头列表（shot list） |
| 分镜绘制 | 画出每个镜头的构图、运镜方式（手绘或软件） |
| 技术标注 | 标出每个镜头需要的镜头焦段、灯光方案、特殊设备 |
| 拍摄日程 | 根据分镜编排拍摄日程（按场景/按演员） |

**典型产出**：一份50-200页的分镜头画板 + 拍摄日程表。

#### 2.3 选角（2-3周，可与分镜并行）

| 步骤 | 说明 |
|------|------|
| 角色需求分析 | 林一鸣（14岁少年 & 20+青年）、林建国、赵建平、王海燕等 |
| 发布选角信息 | 演员招募渠道 |
| 试镜 | 重点是林一鸣——要能演出"沉默但有力量"的感觉 |
| 定角 | 签订合同 |

**特别角色**：
- **小七（机器人）**：有三种实现方案
  - 方案A：实体机器人（成本高，需要有硬件团队支持）
  - 方案B：穿灰色紧身服的演员（后期特效替换）
  - 方案C：纯CGI（成本较高，但最灵活）
  - **推荐**：B方案为主，关键特写用C方案增强

#### 2.4 场景与美术设计（2-3周）

| 场景 | 说明 | 实现方式 |
|------|------|---------|
| 农村老家（2008年） | 老式砖瓦房、麦田 | 实景拍摄（推荐河南/河北农村） |
| 大学宿舍 | 上下铺、杂物堆 | 搭景或实景 |
| 比赛场馆 | 体育馆 | 租用或使用学校体育馆 |
| 实验室 | 设备、示波器、3D打印机 | 实景（联系大学实验室） |
| 智能化农场 | 农田 + 设备 | 实景拍摄 |
| 公司（第8集） | 现代化办公 | 租用场地 |

#### 2.5 道具准备（2-3周）

**关键道具清单**：

| 道具 | 说明 | 优先级 |
|------|------|--------|
| 父亲的手套 | 破旧劳保手套，贯穿全剧 | 必需品 |
| PLA机器人骨架（初代机） | 3D打印，40cm高 | 需制作 |
| "铁牛一号"比赛机器人 | 四轮+机械臂 | 需制作或借用 |
| 小七（各种版本） | V0.1/V0.3/V2.0 | 核心道具 |
| 农用机器 | 除草机、自动灌溉、无人机 | 可租用或借用 |
| 旧电脑、老手机 | 符合年代设定 | 可购买二手 |

**小七制作优先级最高**——建议与硬件团队合作，至少做出能动的版本。如果实在做不出实体，方案B（演员+特效）是更现实的选择。

#### 2.6 设备与拍摄方案

| 设备 | 说明 |
|------|------|
| 摄影机 | 至少2台，建议索尼FX系列或RED（租赁） |
| 镜头 | 变焦+定焦组 |
| 灯光 | 自然光+LED灯组 |
| 收音 | 枪麦+小蜜蜂 |
| 稳定器 | DJI RS系列 |
| 无人机 | 用于麦田航拍 |
| 监视器 | 导演监看 |

### 阶段3：中期拍摄（2-4周）

#### 3.1 拍摄日程安排

建议按场景集中拍摄（而非按集），提高效率：

| 拍摄周 | 场景集中 | 涉及集数 |
|--------|---------|---------|
| 第1周 | 农村外景+内景 | 第1、5、8集 |
| 第2周 | 学校+实验室+宿舍 | 第1-4集 |
| 第3周 | 比赛场馆+农田示范区 | 第1、5-6集 |
| 第4周 | 公司+补拍+特殊镜头 | 第7-8集 |

#### 3.2 拍摄注意事项

| 事项 | 说明 |
|------|------|
| 麦田场景的时效性 | 麦收季节一般在6月（北方），需提前协调 |
| 雨天备用方案 | 农村外景受天气影响大 |
| 机器人操作员 | 小七需要有操作员在现场 |
| 儿童演员 | 14岁林一鸣需要小演员，遵守相关规定 |
| 时间预算 | 每天实际有效拍摄约6-8小时 |
| 回看检查 | 每天收工后回看当天素材，确认是否需要补拍 |

### 阶段4：后期制作（6-10周）

#### 4.1 剪辑（3-4周）

| 任务 | 说明 |
|------|------|
| 素材整理 | 代理转码、素材同步、打标签 |
| 粗剪 | 按剧本顺序拼接，确定每集节奏 |
| 精剪 | 调整镜头时长、转场、节奏 |
| 定剪 | 画面锁定 |

**关键原则**：
- 每集15-20分钟，节奏不能拖
- 技术场景要"快"——不要为了展示代码而放慢节奏
- 情感场景要"慢"——给沉默留时间

#### 4.2 视觉特效（2-4周，与剪辑并行）

| 任务 | 说明 | 预估时间 |
|------|------|---------|
| 小七CGI增强 | 替换灰色紧身服为机器人外观 | 最耗时的部分 |
| 代码屏幕合成 | 将真实代码叠加到屏幕素材上 | 1周 |
| 色彩分级 | 统一全剧色调 | 1周 |
| 字幕 | 中文字幕+可选英文字幕 | 0.5周 |

#### 4.3 声音设计（2-3周，与剪辑并行）

| 任务 | 说明 |
|------|------|
| 对白编辑 | 清理噪音、统一音量 |
| 音效设计 | 环境音（田间的风、机器运转）、机器人动作音效 |
| 拟音（Foley） | 脚步声、物体碰撞等细节音效 |
| 混音 | 对白、环境、音效、音乐的比例平衡 |

**重点音效设计**：
- 小七走路的声音（机械+轻柔）
- 麦田的风声（贯穿全剧的环境音）
- 焊接/电路工作的声音（ASMR风格）

#### 4.4 音乐作曲（2-3周）

| 任务 | 说明 |
|------|------|
| 主题曲创作 | 作词、作曲、录制 |
| 配乐作曲 | 分段场景配乐写作 |
| 配乐录制 | 真人演奏或合成器 |
| 配乐编辑 | 与画面同步对位 |

**建议合作方式**：
- 主题曲：找独立音乐人合作（成本可控且能有特色）
- 配乐：可以使用版权音乐库 + 定制关键场景配乐

#### 4.5 审片与修改（1周）

| 任务 | 说明 |
|------|------|
| 内部审片 | 团队集体观看，发现问题 |
| 试映 | 邀请小范围观众观看 |
| 修改 | 根据反馈调整 |
| 最终定稿 | 提交最终母版 |

### 阶段5：发布与宣发（2-4周）

#### 5.1 发布平台选择

| 平台 | 适合性 | 说明 |
|------|--------|------|
| B站 | ★★★★★ | 科技+农村+励志是目前B站热门品类 |
| 抖音/快手 | ★★★★☆ | 竖屏短剧，需重新剪辑为竖版 |
| 视频号 | ★★★★☆ | 微信生态传播 |
| YouTube | ★★★☆☆ | 如果有英文字幕 |
| 爱优腾 | ★★★☆☆ | 需要发行渠道 |

**推荐首发策略**：B站为主（完整版），抖音/快手为辅（剪辑成15条30-60秒的短视频引流），视频号作为社交传播节点。

#### 5.2 宣发物料准备

| 物料 | 说明 |
|------|------|
| 预告片 | 30秒/60秒/90秒三个版本 |
| 海报 | 主视觉海报 + 角色海报 + 剧情海报 |
| 短视频切片 | 关键片段，用于社交媒体分发 |
| 幕后花絮 | 拍摄过程、特效揭秘 |
| 幕后纪录片 | 10-15分钟的"如何制作" |
| 导演访谈 | 如果愿意出镜的话 |
| 剧照包 | 高清剧照供媒体使用 |

#### 5.3 发布节奏

| 时间 | 动作 |
|------|------|
| T-2周 | 发布预告片 |
| T-1周 | 发布海报 + 角色介绍 |
| T-0 | 首播第1-2集 |
| T+1周 | 第3-4集 |
| T+2周 | 第5-6集 |
| T+3周 | 第7-8集（大结局） |

**每周两集**的节奏，保持热度持续，给观众讨论空间。

## 三、团队规模与预算建议

### 最小可行团队（6-8人）

| 角色 | 人选建议 |
|------|---------|

| 演员 | 按角色聘请 |
| 场务 | 1人 |

### 理想团队（12-15人）

在上述基础上增加：副导演、化妆师、服化道助理、摄影助理、现场制片、VFX特效师、配乐师。

### 预算层级预估

| 层级 | 预算范围 | 说明 |
|------|---------|------|
| 极低预算 | 5-10万 | 设备租赁、演员、少量道具；大量靠DIY和友情支持 |
| 低预算 | 10-30万 | 可以租到好设备、支付合理报酬、有基础后期 |
| 中等预算 | 30-80万 | 专业团队、版权音乐、VFX外包、宣发费用 |
| 较高预算 | 80万+ | 商业级别制作，全流程专业团队 |

**推荐起始**：10-30万档，先做出来，验证品质后再看是否需要追加。

## 四、风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 小七机器人做不出来或效果差 | 中 | 高 | 准备工作方案B（演员+特效），不要把所有希望押在硬件上 |
| 麦田拍摄错过季节 | 中 | 中 | 提前半年确定拍摄时间，或使用绿幕+后期合成 |
| 资金不足 | 高 | 高 | 分阶段投入，先拍前2集测试品质，再找投资 |
| 演员档期问题 | 中 | 中 | 集中拍摄（把某个演员的戏集中几天拍完） |
| 技术细节被专业人士吐槽 | 低 | 中 | 尽早找技术顾问审稿 |
| 农村戏拍不出质感 | 中 | 中 | 选景很重要，提前踩点；参考《隐入尘烟》的摄影 |

## 五、建议的推进策略

### 策略A：全流程稳扎稳打（推荐）

先不急着拍，把剧本和前期准备做扎实。

1. **现在 → 2周后**：完成阶段1（全部剧本定稿）
2. **2-6周后**：完成阶段2（分镜、选角、场景、道具）
3. **6-10周后**：拍摄
4. **10-18周后**：后期制作
5. **18-20周后**：发布

**优势**：准备充分，品质有保障。
**劣势**：战线较长，需要持续投入精力。

### 策略B：MVP（最小可行产品）先行

先拍一集（推荐第1集或第4集）作为"样片"：

1. **现在 → 2周后**：写完第1集+第4集剧本
2. **2-4周后**：准备第1集的道具和场景
3. **4-5周后**：拍完第1集
4. **5-8周后**：完成第1集后期
5. 用第1集成片去找投资/合作/上众筹
6. 有了资金后再拍剩余集数

**优势**：风险低，可以测试市场反应。
**劣势**：如果第1集反响不好，续集动力不足。

### 策略C：边做边发

用"制作纪录片"的方式边拍边发，每周更新：

1. 同时推进剧本+拍摄+后期
2. 每两周更新一集
3. 同时在B站发"制作vlog"吸引关注

**优势**：有观众互动，可以边做边调整。
**劣势**：对团队协作要求极高，不适合新手团队。

---

**建议**：先走策略B（拍一集样片），看反馈后再决定是全流程投入还是找投资。这样风险最低，而且样片做好了天然就是宣发物料。
