# 《钢铁之子》短剧 —— AI全流程制作计划

> 制定日期：2026-05-21
> 硬件基础：RTX 3060 12G（本地）+ 云GPU（按需租用）
> 目标：B站/抖音/视频号发布的高质量AI短剧
> 制作人背景：RL+LLM+具身智能研究者，Python技术栈

---

## 一、核心思路

### 为什么要用AI做（而不是传统拍摄）

| 维度 | 传统拍摄 | AI制作 | 优势 |
|------|---------|--------|------|
| 演员 | 需要选角、签约、档期协调 | 无需真人演员 | AI完胜 |
| 场景 | 实景踩点/搭景，受天气季节限制 | 文字生成/3D场景 | AI完胜 |
| 道具（小七机器人） | 需要做实体或高成本特效 | 3D模型+AI渲染 | AI完胜 |
| 特效 | 专业VFX团队 | 图像/视频生成模型 | AI便宜得多 |
| 时间 | 4-8个月 | 4-8周（单人） | AI更快 |
| 成本 | 10-30万起 | 约5000-15000元 | AI优势巨大 |
| 上限 | 真实感天花板很高 | 目前仍有AI痕迹 | 传统更优 |

**结论**：AI制作在成本、时间、自由度上全面碾压传统拍摄。缺点是"真实感"有上限——但2026年的AI视频工具，只要流程正确，已经能做到"观众第一眼分不清"的水平。

### 我们的策略：AI原生制作，不做"传统拍摄的劣质替代"

错误做法：用AI模拟"拍电影"（找AI当演员演戏）→ 生硬、恐怖谷
正确做法：用AI做 **"只有AI才能做出来的视觉风格"**→ 独特性、艺术感

**本剧的视觉风格建议**：写实+轻度风格化——保留真实质感但不追求完全还原真人实拍，而是做出一种"像实拍但更干净/更理想化"的画面。

| 任务 | 工具 | 可行？ |

```

   ↓
```

## 四、阶段详解

---

### 阶段1：剧本与分镜（1-2周，完全本地）

#### 1.1 最终决策会

| 决策项 | 你的选择 | 备注 |
|--------|---------|------|
| 剧名 | 待定 | 会影响宣发和视觉风格 |
| 集数 | 待定 | 建议先做2-3集测试，爆了再做完 |
| 结尾方式 | 待定 | 会影响最终画面设计 |
| 视觉风格 | 写实+轻度风格化 | 建议做2版风格对比再定 |

#### 1.2 剧本拆解为镜头列表

传统分镜：画图
**AI分镜：写详细的文字描述**（因为AI模型需要 prompt）

**每个镜头需要写清楚**：

```
[镜头1-01]
画面描述：14岁的林一鸣在黄昏的麦田里割麦子，瘦小的背影，远处乌云压境。
视角：全景，略带俯视，镜头缓慢推进
色调：金黄偏暖，略有压抑感
人物状态：光着膀子，手上血泡，动作吃力
时长：8秒
对白：无（画外音）
转场：切
```

这一步决定了AI能生成什么——**prompt写得好，后期80%的调试工作就省了**。

**建议工具**：

| 用途 | 工具 | 说明 |
|------|------|------|
| 剧本写作 | Claude / DeepSeek | 你已经用得很好了 |
| 镜头拆解 | 我直接帮你做 | 把每集的剧本拆成30-50个镜头描述 |
| 提示词辅助 | 我帮你生成每镜头的完整prompt | 适配不同的AI视频模型 |

### 阶段2：角色与世界观设计（1-2周，本地+云）

这是 **最关键的阶段**——角色设计不好，后面所有画面里角色长相都不一样，观众直接出戏。

#### 2.1 角色视觉设计（使用 AI 图像生成）

| 角色 | 需要生成的视觉素材 | 工具 |
|------|------------------|------|
| 林一鸣（14岁） | 正面/侧面/3/4面肖像，不同表情 | SDXL + ComfyUI |
| 林一鸣（20+岁） | 同上 + 穿不同服装（学生/实验室/回家） | SDXL + ComfyUI |
| 林一鸣（硕士毕业） | 同上 | SDXL + ComfyUI |
| 林建国（父亲） | 肖像、表情包 | SDXL + ComfyUI |
| 赵建平（导师） | 肖像、表情包 | SDXL + ComfyUI |
| 王海燕（师妹） | 肖像、表情包 | SDXL + ComfyUI |
| 小七（机器人V0.1） | 3D软件建模或AI生成概念图 | Blender / Meshy / SD |
| 小七（V0.3/V2.0） | 同上，外观升级 | Blender / Meshy / SD |

**角色一致性方案**：

这是AI短剧最大的技术难点——同一角色在不同镜头里长得不一样。

解决方案（三种方式，复杂度递增）：

| 方案 | 原理 | 复杂度 | 效果 |
|------|------|--------|------|
| **A. IP-Adapter + FaceID** | 用一张角色照片固定长相 | ★★☆ | 80%相似度，够用 |
| **B. LoRA微调** | 为每个角色训练一个轻量模型 | ★★★ | 90%+相似度，推荐 |
| **C. InstantID/ID-Animator** | 更高级的ID保持方法 | ★★★★ | 最好但最慢 |

**推荐**：走方案B。为剧中5个主要角色各训练一个LoRA（每个角色约需要20-50张参考图，训练时间约30分钟/个）。

#### 2.2 场景视觉设计

| 场景 | 参考风格 | 生成方式 |
|------|---------|---------|
| 农村麦田（2008年） | 金黄色调，略带怀旧 | ControlNet + 真实照片作为条件图 |
| 大学宿舍 | 杂乱、暖光、堆满零件 | 文本生成 |
| 比赛场馆 | 明亮、热烈、运动感 | 文本生成 |
| 实验室 | 冷色调、科技感、设备堆叠 | 文本生成 |
| 智能化农田 | 科技+自然的结合 | 文本生成 |
| 公司办公室 | 现代、简洁、落地窗 | 文本生成 |

**重要**：每个场景也建议训练一个"场景LoRA"或保存固定的prompt模板，保证同一场景在不同镜头里一致。

#### 2.3 小七机器人的3D资产

小七是 **核心资产**，不能只靠AI视频生成碰运气。建议用3D建模做出来，然后在视频生成时作为"条件控制"。

**推荐方案**：

| 步骤 | 工具 | 说明 |
|------|------|------|
| 低模生成 | Meshy / TripoSR | 文本/图片生成3D模型，5分钟 |
| 精模/细节 | Blender | 手动添加细节、关节、材质 |
| 纹理贴图 | AI纹理生成（Materialize） | 金属质感、划痕等 |
| 绑定/骨骼 | Blender | 让机器人可以摆pose |
| 渲染为参考图 | Blender Cycles / Eevee | 生成多角度参考图，用于AI视频的条件输入 |

**时间预估**：
- Meshy生成低模：30分钟
- Blender精修+材质：2-3天（如果零基础Blender需要1-2周学习时间）
- 渲染参考图集：2小时

**或者更现实的方案**：
- 先找开源的机器人3D模型（Sketchfab / Hugging Face / 淘宝买）
- 修改颜色、添加特征变为"小七"
- 生成多角度参考图

### 阶段3：音频制作（1周，完全本地）

#### 3.1 语音合成

| 角色 | 推荐工具 | 说明 |
|------|---------|------|
| 林一鸣（画外音/对白） | CosyVoice / GPT-SoVITS | 需要找参考声音 |
| 林建国（父亲） | CosyVoice | 偏沙哑、中老年男性 |
| 赵建平（导师） | CosyVoice | 中年男性，稍严肃 |
| 王海燕（师妹） | CosyVoice | 年轻女性，活泼 |
| 陈总（CEO） | CosyVoice | 中年男性，精明 |
| 小七（机器人） | CosyVoice + 音效处理 | 语音合成后加机械感 |

**方案**：
1. 找6个声音样本（可以自己录、找朋友、或用AI语音库）
2. 用GPT-SoVITS或CosyVoice做声音克隆
3. 输入剧本台词，批量生成语音
4. 在剪辑软件中对齐画面

**预算**：几乎为0（都是开源工具，3060跑得动）

**时间**：生成全部8集对白约2-3天（主要是调试声音的时间）

#### 3.2 音效与环境声

| 类型 | 来源 | 工具 |
|------|------|------|
| 环境声（麦田风声） | 音效库 | Freesound / Artlist |
| 机器运转声 | AI生成 | AudioLDM / Soundraw |
| 机器人脚步声 | AI生成 | AudioLDM |
| 焊接/电路 | 音效库 | Freesound |
| 冲击音/转场 | 音效库 | 各种SFX包 |

**开源免费音效库**：
- Freesound.org（CC协议，免费）
- Pixabay音效（免费商用）
- Mixkit（免费）

#### 3.3 背景音乐

| 方案 | 优点 | 缺点 | 成本 |
|------|------|------|------|
| A. AI音乐生成 | 可定制、零成本 | 质量参差 | 0元 |
| B. 版权音乐库 | 质量高、版权明确 | 按首付费 | 约50-200元/首 |
| C. 找独立音乐人定制 | 独一无二 | 贵 | 500-2000元/首 |

**推荐**：主题曲找独立音乐人定制（500-1000元，一首歌），配乐用AI生成 + 版权音乐库混合。

**AI音乐工具**：
- Suno（目前最好，付费订阅约10美元/月）
- Udio（质量接近Suno）
- MusicGen（开源，本地跑，但质量一般）

### 阶段4：视频生成（2-3周，云GPU为主）

这是 **核心阶段**，也是工作量最大的阶段。

#### 4.1 AI视频生成工具对比（2026年）

| 工具 | 质量 | 可控性 | 成本 | 推荐场景 |
|------|------|--------|------|---------|
| **Runway Gen-3** | ★★★★★ | ★★★ | 贵（约0.5美元/秒） | 关键镜头（小七觉醒、结局） |
| **Kling（可灵）** | ★★★★☆ | ★★★ | 中等 | 写实场景推荐 |
| **Pika 2.0** | ★★★★☆ | ★★★ | 中等 | 表情/人物镜头 |
| **Sora** | ★★★★★ | ★★☆ | 最贵 | 现在OPENAI还是不开源 |
| **CogVideoX** | ★★★★ | ★★★★☆ | 免费（开源） | 本地可部署，可控性强 |
| **AnimateDiff** | ★★★☆ | ★★★★★ | 免费（开源） | 最多控制方式，推荐首选 |

**推荐策略**：

```
日常镜头（80%）→ CogVideoX（开源，可控性好）
关键镜头（15%）→ Kling / Runway（高质量）
特效镜头（5%）→ 3D渲染+AI增强
```

#### 4.2 核心工作流（以AnimateDiff/CogVideoX为例）

```
剧本分镜  →  文字prompt  →  图生视频（用参考图）
                              ↑
角色LoRA ────────────────────┘
      ↑
场景参考图  → ControlNet
```

**每一步的详细流程**：

1. 从阶段2准备好的角色参考图 + 场景参考图
2. 用ComfyUI搭建工作流（需要花1-2天搭建好模版，之后批量生成）
3. 每个镜头运行图生视频，生成5-10秒片段
4. 每个镜头生成3-5个候选，挑选最好的
5. 如果不满意的镜头需要调prompt或换参考图重做

**每个镜头的耗时**（以云GPU 4090为例）：
- 512x768分辨率：约2-3分钟/镜头（5秒）
- 1024x1024分辨率：约5-8分钟/镜头（5秒）
- 生成3-5个候选：约10-30分钟/镜头

**全部8集的基础估算**：
- 每集约30-50个镜头
- 全部镜头素材：约240-400个镜头候选
- 总GPU时间：约80-200小时（云GPU时间）
- 折合成本：约160-400元（按2元/小时的4090算）

#### 4.3 质量控制

| 常见问题 | 原因 | 解决方案 |
|---------|------|---------|
| 角色长相不一致 | 没有用LoRA或IP-Adapter | 必须在阶段2训练好LoRA |
| 画面突变/扭曲 | 视频模型的长距离一致性差 | 缩短每个片段（3-5秒），制作时重叠 |
| 动作不自然 | 大动作AI不好做 | 优先做中近景，大动作用3D辅助 |
| 物体穿模 | 视频模型物理理解有限 | 增加ControlNet控制 |
| 人脸崩坏 | 手指和脸是AI的弱项 | 用局部修复/超分插件修复 |

#### 4.4 超分与增强

生成的视频分辨率可能不够，需要用超分模型提升：

| 工具 | 用途 | 3060能跑？ |
|------|------|-----------|
| Real-ESRGAN | 视频超分（2x/4x） | ✅ 完全没问题 |
| Topaz Video AI | 最佳超分软件 | ❌ 付费，但效果好 |
| BasicSR | 开源超分框架 | ✅ 可以 |

**流程**：
1. 生成低分辨率（512x768）的原始片段
2. 用Real-ESRGAN超分到1080p
3. 调整帧率到24fps或30fps

### 阶段5：剪辑与合成（1周，本地）

#### 5.1 剪辑工具

| 工具 | 推荐理由 |
|------|---------|
| **DaVinci Resolve** | 免费专业级，剪辑+调色+混音一站式 | **强烈推荐** |
| Premiere Pro | 行业标准，但付费 | 如果有版权就用 |
| 剪映专业版 | 简单易用，AI字幕功能强 | 适合新手 |
| CapCut（剪映国际版） | 同上 | |

**推荐**：DaVinci Resolve免费版已足够。功能强大，而且免费。

#### 5.2 剪辑流程

```
素材导入
  │
  粗剪（按分镜顺序拼）
  │
  精剪（切节奏、删冗余）
  │
  音频同步（语音+音效+音乐）
  │
  调色（统一色调）
  │
  字幕（自动生成+校对）
  │
  输出
```

**效率技巧**：
- AI生成时建议统一分辨率、帧率、编码格式
- 素材按"集数_镜头编号"命名，方便定位
- DaVinci支持代理剪辑（先剪低分辨率，最后替换为高分辨率）

#### 5.3 调色方案

根据剧本的"三段式"情绪走向：

| 阶段 | 对应集数 | 色调 | 效果 |
|------|---------|------|------|
| 童年/农村 | 第1集前半、第5集 | 暖黄偏金，轻微胶片颗粒 | 怀旧、温暖但压抑 |
| 学校/拼搏 | 第1集后半、2-3集 | 冷白+蓝调 | 专注、奋斗感 |
| 技术突破 | 第4集 | 蓝→金渐变 | AI觉醒的高潮时刻 |
| 科技农业 | 第5-8集 | 明亮、金黄+绿色 | 希望、升华 |

## 七、建议的推进策略

### 建议分三步走

#### 第一步：技术验证（1-2周，预算0）

不急于做全片。先完成以下目标：

1. **搞懂ComfyUI**，能生成风格一致的图像
2. **训练一个角色LoRA**（比如林一鸣青年版）
3. **用AnimateDiff/CogVideoX生成一段5秒的视频**
4. **跑通语音合成**

**通过标准**：生成一段主角在麦田里走路的5秒视频，画面质量你满意。

#### 第二步：试制一集（2-3周，预算500-800元）

选第1集或第4集做"样片"：

1. 完成全部镜头拆解
2. 批量生成视频片段
3. 加上语音和音乐
4. 剪辑成片

**通过标准**：你愿意把这一集发给朋友看。

#### 第三步：全片制作（4-6周，预算2000-3000元）

1. 用试制积累的经验批量生产
2. 保持角色一致性
3. 统一后期调色
4. 逐集发布

## 八、你现在立刻可以做的事情

1. **安装ComfyUI**（在你的3060上）
2. 下载一个写实风格的SDXL模型（如 **RealVisXL** 或 **JuggernautXL**）
