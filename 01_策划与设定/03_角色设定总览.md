## 林一鸣（男主）

| 维度 | 设定 |
|------|------|
| 童年 | 干农活（补种、除草等非标作业），看《我爱发明》自己动手做玩具，喜欢科幻动画 |
| 本科 | 省属普通一本院校自动化专业；动手/电路/控制/编程拔尖，其他一般；机器人大赛团队奖（技术核心非队长）；接触智能化运维（SCADA、工业自动化等） |
| 保研/考研 | 排名不够→保研失败→考研过线复试被刷→调剂 |
| 硕士 | 导师赵建平；重建实验室；"机器人杂货铺"6人群像 |
| 感情 | 大学初恋苏晚晴（研二分手），最终与顾知夏在一起 |
| 家庭 | 父亲林建国（农民）、母亲杨秀兰（因病致残） |
| 创业 | "一鸣智能科技有限公司"，通用人形机器人"小七" |
