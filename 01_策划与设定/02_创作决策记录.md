## 角色补充设定

### 林一鸣的童年

- 从小跟着父母下地干农活，插秧、割麦、除草、施肥都做过，深知每种农活的辛苦
- 小时候经常看央视《我爱发明》节目，深受影响
- 喜欢看科幻类动画片
- 自己动手制作玩具（弓箭、弹弓等简单机械）
- 会模仿《我爱发明》里的发明制作小工具
- 但当时能力有限，也没有资金支持

### 林一鸣的大学

- 省属普通一本院校（非211），本科自动化专业
- 大量时间投入自学编程、机械建模、电路设计；动手、电路、控制、编程类科目成绩拔尖，但其他科目成绩一般，综合绩点排名不够靠前
- 参加全国机器人大赛：**团队获奖，他是技术核心但不是队长**
- 大学期间通过课程设计、实训项目和自学接触**智能化运维**：工业自动化、传感器网络、SCADA（数据采集与监控）、预测性维护等内容；曾帮导师做过小型产线监控系统
- 综合绩点排名不够靠前，保研失利

### 林一鸣与苏晚晴的感情线

- **相识方式**：通过朋友介绍认识
- **恋爱时长**：3年（大学期间）
- **恋爱状态**：大学期间感情很好，女主很体贴、理解林一鸣
- **分手时间**：研二期间（异地一年多后，女主工作也一年多了，两世界不再重合）
- **分手提出方**：苏晚晴提出
- **分手原因**：多重因素叠加
  - 双方父母的反对（主要来自女方家庭）
  - 苏晚晴毕业后考上税务局回老家工作，异地恋
  - 初入职场的苏晚晴渴望陪伴，而林一鸣忙于机器人和学业无法在身边
  - 两个人在不同的世界里逐渐走远——不是谁变了，是各自的人生轨道不再重合
  - 最终没有谁对谁错，只是人生选择了不同方向

### 小七机器人的定位

- **类型**：通用人形机器人平台（非单一功能机器人）
- **技术栈**：机械结构 + 电路设计 + 运动控制 + **大模型技术**
- **智能化来源**：大模型技术赋予其理解、推理、适应非标准化场景的能力
- **应用领域**：农业（起点）→ 家政、养老、巡检等（扩展）
- **核心价值**：不是替代单一工种，而是填补"标准化机器与人工之间的缝隙"——能做那些规则写不清楚、场景千变万化的活

### 全剧技术路线

```
底层（硬件层）：机械结构设计 → 电路/驱动 → 运动控制
中层（系统层）：传感器融合 → 路径规划 → 多机协同
顶层（智能层）：大模型（理解/推理/决策）→ 自然语言交互 → 自适应学习
```
