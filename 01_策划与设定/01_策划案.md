# 策划案：短剧《麦田里的钢铁》

---

## 核心信息

| 项目 | 内容 |
|------|------|
| 剧名 | 《麦田里的钢铁》 |
| 类型 | 青春励志 / 科技热血 / 乡土情怀 |
| 集数 | 8集，每集15-20分钟 |
| 核心Slogan | "他造的机器人，能插秧，能摘果，还能叫一声'妈'。" |

## 故事内核

一个从农村走出来的普通学生，因为深知体力劳动的苦——小时候在麦田里割麦子割到双手血泡，看着父亲光着手干活，母亲患病致残——立下志向：**要让机器人替人弯腰**。

本科期间自学编程、机械建模、电路设计，参加全国机器人大赛获一等奖。但因精力集中在动手、电路、控制类科目上，其他科目成绩一般，综合绩点排名不够靠前，保研失利。考研初试过线，复试被刷，调剂到一所普通二本理工学院。

在普通院校没有堕落，反而在导师赵建平的支持下，用三个月重建了实验室控制系统。在"机器人杂货铺"发烧友群中结识各路技术人——从行业大佬到高中生，从退休总工到汽修厂电工——林一鸣像拼图的人，把所有人的知识整合到一起。在王海燕的协助下，终于做出初代人形机器人"小七"。之后将技术应用于农业，为母亲制作外骨骼机器人帮助她重新站立，搭建智能化农场，政府推广……科技公司上门收购——但他拒绝了，因为 **"他的目标是让每一个农民都用得起"**。

## 人物角色表

| 角色 | 身份 | 性格关键词 | 人物弧光 |
|------|------|-----------|---------|
| **林一鸣**（男一） | 硕士毕业生，机器人天才 | 沉默坚韧、极度专注、不善社交但内心深处有炙热的信念 | 从"被农活压弯腰的农村娃"到"让机器人替人弯腰的造物主" |
| **苏晚晴** | 林一鸣的大学初恋 | 温柔善良、内心有挣扎，最终选择了父母期望的安稳路 | 从"我相信你能做出来"到各自走上不同的人生 |
| **赵建平** | 硕士导师，自动化学院副院长 | 外表严厉、惜才如命、刀子嘴豆腐心 | 从"觉得这学生不务正业"到"倾家荡产支持他" |
| **王海燕** | 研一师妹，技术搭档 | 开朗、动手能力强、欣赏师兄但保持分寸 | 从好奇到成为最坚定的技术伙伴 |
| **林建国** | 林一鸣的父亲 | 老实巴交的农民，不懂技术但懂道理 | 从"读书有啥用"到"我儿子造的机器比我种得还好" |
| **杨秀兰** | 林一鸣的母亲 | 温柔坚韧，因病致残但从未抱怨 | 从"拖累儿子"到被儿子的外骨骼机器人重新扶起来 |
| **张建设** | 当地镇领导 | 实干派、有远见 | 从"瞎折腾"到"全镇推广智能化农业" |
| **陈翼** | 科技公司CEO | 商人嗅觉敏锐，有情怀但更看重利益 | 从"想买断技术"到"被理想打动" |
| **小七**（机器人） | 人形机器人 | 初始机械呆板，逐渐展现"人性化" | 从工具到伙伴，是林一鸣理想的具象化 |

## 风格基调

- **前期（1-3集）**：乡村贫穷但温暖，大学拼搏，燃+虐
- **中期（4-6集）**：技术攻关，草根逆袭，热泪+热血
- **后期（7-8集）**：科技改变乡村，大格局升华，泪目+震撼

## 核心冲突

1. **人与体力劳动**：机器人替人弯腰——个人理想
2. **资源与理想**：普通二本的简陋条件 vs 超越时代的野心
3. **资本与初心**：高价收购 vs "让农民用得起"
4. **技术与道德**：当机器人有了"意识"，人机关系如何定义
